📦 Anabole Pakete

Läuft auf der Massen-Unterstützung im Versammlungsplatz. Liest beim Start die Truppen aller angezeigten Dörfer ein und zeigt eine Leiste über der Dorftabelle: Paket zusammenstellen (Speer/Schwert/sKav/Späher), Anzahl der gewünschten Pakete eintragen, auf „Übernehmen“ klicken - das Script hakt die passenden Dörfer automatisch an und trägt die berechneten Truppenzahlen ein. Über dem Button „Unterstützung schicken“ erscheint anschließend eine Anzeige, wie viele Pakete tatsächlich eingetragen wurden (grün = volle gewünschte Anzahl erreicht, rot = weniger möglich).

Zwei Modi für die Zusammensetzung eines Pakets: „Nur volle Pakete“ an bedeutet, jedes Paket kommt komplett aus einem einzigen Dorf; aus bedeutet, die Einheiten eines Pakets dürfen sich auch aus mehreren Dörfern zusammensetzen. Zusätzlich lässt sich je Einheit eine Menge festlegen, die pro Dorf immer zurückgehalten wird (z.B. als Grundverteidigung), und per Priorität wählen, ob zuerst die nächstgelegenen oder die am weitesten entfernten Dörfer herangezogen werden. Alle Einstellungen werden im Browser gespeichert.

Es wird nichts automatisch abgeschickt - das Script hakt Dörfer an und füllt Felder, so wie es auch per Hand ginge; „Unterstützung schicken“ musst du selbst klicken, nachdem du die eingetragenen Werte kontrolliert hast.

Version v0.4.0
Voraussetzung Massen-Unterstützung im Versammlungsplatz geöffnet (screen=place&mode=call)
Einheiten Speer, Schwert, Schwere Kavallerie, Späher (nur auf der Welt tatsächlich vorhandene Einheiten werden angezeigt)
Einstellungen-Speicher Browser (localStorage), bleiben zwischen Aufrufen erhalten
Versendet selbst? Nein - hakt Dörfer an und trägt Truppen ein, „Unterstützung schicken“ bleibt ein manueller Klick

Installation (Desktop)

Ziehe diesen Button in deine Lesezeichenleiste. Öffne danach im Spiel die Massen-Unterstützung und klicke auf das Lesezeichen, um das Script zu starten.

📦 Anabole Pakete starten

Oder diesen Code in ein Lesezeichen einfügen/kopieren:

javascript:$.getScript('https://marlongsimo.github.io/DS-Scripts/scripts/anabolePakete.js');

Nutzung auf eigene Verantwortung. Vor dem ersten Einsatz die berechneten Haken und Truppenzahlen kontrollieren, bevor du auf „Unterstützung schicken“ klickst - vor allem bei „Nur volle Pakete“ aus kann sich ein Paket über mehrere Dörfer verteilen. Bitte vorab die Regeln deines Servers zu Skripten/Bookmarklets prüfen.
