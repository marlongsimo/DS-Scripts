v1.0 Dorfgruppen Koordinaten-Import

🗂️ Gruppen-Tool

Öffnet einen Dialog mit einem Textfeld für Koordinaten. Beim Klick auf „Dörfer auswählen“ werden alle eingefügten Koordinaten (Format 123|456) gegen die eigene Dorfliste abgeglichen – Dörfer, die einem nicht selbst gehören, werden ignoriert (Ausgabe in der Konsole). Aus den gefundenen eigenen Dörfern wird anschließend eine Liste mit Checkboxen gebaut, aus der sich die passende Zielgruppe auswählen und mit „Add“ bestätigen lässt – dieselbe serverseitige Aktion wie beim manuellen Hinzufügen über die Dorfgruppen-Verwaltung.

Zusätzlich lässt sich schon vor dem Import eine Zielgruppe vorauswählen und über die Checkbox „Gruppe vorher komplett leeren“ festlegen, dass alle aktuell in dieser Gruppe enthaltenen Dörfer zuerst entfernt werden, bevor nur die neu eingefügten Koordinaten hinzukommen. Über den Button „Nur Gruppe komplett leeren“ lässt sich eine Gruppe auch ganz ohne neuen Import leeren. Die Dorfliste (für den Koordinaten-Abgleich) wird wie im Original 24 Stunden lang im Browser zwischengespeichert, damit nicht bei jedem Aufruf neu geladen werden muss.

Version v1.0
Voraussetzung Manuelle Dorfgruppe(n) angelegt
Koordinaten-Format Ein oder mehrere 123|456, beliebig getrennt
Dorfliste-Cache 24 Stunden (Browser-Speicher)
Bedienung Bookmarklet an beliebiger Stelle im Spiel anklicken

Installation (Desktop)

Ziehe diesen Button in deine Lesezeichenleiste. Klicke ihn danach im Spiel an, um den Dialog zu öffnen.

Installation (Handy: iPhone/Android)

Auf dem Handy lässt sich das Bookmarklet nicht per Drag & Drop in die Lesezeichen-/Favoritenleiste ziehen. Stattdessen legst du zuerst ein ganz normales Lesezeichen an und ersetzt dessen Adresse danach durch den folgenden Code: 

javascript:$.getScript('https://marlongsimo.github.io/DS-Scripts/scripts/gruppenTool.js');

iPhone (Safari):

  1. Diese Seite (oder eine beliebige andere) über das Teilen-Symbol als Lesezeichen speichern.
  2. Unten auf das Bücher-Symbol tippen → „Lesezeichen“ → „Bearbeiten“ → das eben erstellte Lesezeichen antippen.
  3. Das Adressfeld leeren und den oben kopierten Code einfügen. Als Namen z.B. „Gruppen-Tool“ eintragen und speichern.
  4. Damit es schnell erreichbar ist: das Lesezeichen in den Ordner „Favoriten“ verschieben – es erscheint dann in der Schnellzugriffsleiste beim Öffnen eines neuen Tabs.
  5. Im Spiel einen neuen Tab öffnen und das Lesezeichen aus den Favoriten antippen.

Android (Chrome):

  1. Über das Menü (⋮) → „Lesezeichen“ → „Hinzufügen“ ein neues Lesezeichen anlegen.
  2. Das Lesezeichen antippen und halten → „Bearbeiten“, die URL löschen und durch den oben kopierten Code ersetzen, Namen anpassen und speichern.
  3. Damit es in der Schnellleiste erscheint: in den Chrome-Einstellungen unter „Lesezeichen“ die Lesezeichenleiste aktivieren, oder das Lesezeichen zum Startbildschirm hinzufügen.
  4. Im Spiel das Lesezeichen aus der Leiste antippen.

Nutzung auf eigene Verantwortung. Das „Gruppe leeren“-Feature entfernt Dörfer unwiderruflich aus der gewählten Gruppe (die Dörfer selbst bleiben davon unberührt) – vor dem Bestätigen im Dialog kontrollieren, ob die richtige Gruppe ausgewählt ist.
