v2.0.1 TwForge Berichte & SOS

📤 TwForge Manual Upload

Läuft ausschließlich auf der Übersicht der eintreffenden Angriffe (Berichte > Eintreffende Angriffe). Zwei Buttons plus ein Einstellungen-Zahnrad, sonst nichts - kein automatisches Durchklicken, keine Hintergrund-Automatisierung:

  • „Angehakte Angriffe zu TwForge hochladen“: erzeugt aus den angehakten eingehenden Angriffen den SOS-Anfrage-Text (wie „Hilfe anfordern“) und lädt ihn direkt hoch.
  • „Ordner-Berichte zu TwForge hochladen“: veröffentlicht alle Berichte im eingestellten Quell-Ordner, lädt sie zu TwForge hoch und verschiebt die erfolgreich hochgeladenen anschließend in den eingestellten Ziel-Ordner - der Quell-Ordner (z.B. „Neue Berichte“) bleibt so für den nächsten Lauf frei.
  • „⚙️ Ordner einstellen“: Quell- und Ziel-Ordner werden als Ordner-ID (Zahl) eingetragen - wie beim Katta-Feature von „Anaboles Farmen“. Die ID liest man aus der URL ab, wenn man den Ordner in der Berichtsübersicht anklickt (z.B. ...&group_id=12 → ID ist 12). Einmal gespeichert, bleibt die Wahl im Browser erhalten.
CORS-Hinweis: Das Original ist ein Tampermonkey-Userscript mit GM_xmlhttpRequest, das die Same-Origin-Policy des Browsers umgeht. Diese Bookmarklet-Version läuft ohne Tampermonkey und nutzt stattdessen normales fetch() für die Anfrage an TwForge - das funktioniert nur, wenn die TwForge-API Cross-Origin-Anfragen von der Spieldomain per CORS-Header erlaubt. Schlägt der Upload fehl, in der Browser-Konsole (F12) nach einer CORS-Fehlermeldung schauen.

Installation (Handy: iPhone/Android)

Auf dem Handy lässt sich das Bookmarklet nicht per Drag & Drop in die Lesezeichen-/Favoritenleiste ziehen. Stattdessen legst du zuerst ein ganz normales Lesezeichen an und ersetzt dessen Adresse danach durch den oben erzeugten Code.

iPhone (Safari):

  1. Diese Seite (oder eine beliebige andere) über das Teilen-Symbol als Lesezeichen speichern.
  2. Unten auf das Bücher-Symbol tippen → „Lesezeichen“ → „Bearbeiten“ → das eben erstellte Lesezeichen antippen.
  3. Das Adressfeld leeren und den oben erzeugten Code einfügen. Als Namen z.B. „TwForge Upload“ eintragen und speichern.
  4. Damit es schnell erreichbar ist: das Lesezeichen in den Ordner „Favoriten“ verschieben - es erscheint dann in der Schnellzugriffsleiste beim Öffnen eines neuen Tabs.
  5. Im Spiel einen neuen Tab öffnen und das Lesezeichen aus den Favoriten antippen.

Android (Chrome):

  1. Über das Menü (⋮) → „Lesezeichen“ → „Hinzufügen“ ein neues Lesezeichen anlegen.
  2. Das Lesezeichen antippen und halten → „Bearbeiten“, die URL löschen und durch den oben erzeugten Code ersetzen, Namen anpassen und speichern.
  3. Damit es in der Schnellleiste erscheint: in den Chrome-Einstellungen unter „Lesezeichen“ die Lesezeichenleiste aktivieren, oder das Lesezeichen zum Startbildschirm hinzufügen.
  4. Im Spiel das Lesezeichen aus der Leiste antippen.
